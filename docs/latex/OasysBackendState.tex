    \section{description}\label{sec:description}

    The \kw{OasysBackendState} class replaces standard PHP sessions for storing temporary data on the server side for a specific user. It stores data in a database table (\kw{stateBackend}) instead of using the local file system. This mechanism is especially useful in load-balanced environments where local session files cannot easily be shared across instances.\\
    
    Each user is uniquely identified by a \kw{stateId} which is automatically generated and securely stored in a cookie (\kw{oasysStateBackend}). This cookie is sent alongside each request, analogous to a standard session cookie.


    \section{usage}\label{sec:usage}

    The class is implemented as a Singleton to ensure only one instance is active per request. Its properties are handled dynamically using PHP magic methods, meaning you can directly set or get any arbitrary property you need.\\

    \begin{exampleBox}{Example}
        Creating a new instance or getting one that already exists:\\[0.1cm]
        \kw{\$state = OasysBackendState::getInstance();}\\[0.5cm]
        Setting a dynamic property:\\[0.1cm]
        \kw{\$state->myCustomProperty = \$value;}\\[0.5cm]
        Retrieving a dynamic property:\\[0.1cm]
        \kw{\$value = \$state->myCustomProperty;}\\[0.5cm]
        Checking if the browser has an active state without initializing it:\\[0.1cm]
        \kw{\$isActive = OasysBackendState::browserHasActiveState();}
    \end{exampleBox}
    
    \vspace{0.5cm}
    \textbf{Dependencies:}\\
    This class depends on the \kw{OasysSettings} class for its configuration, \kw{rixPDO} for database interactions, and it may throw \kw{StateExpiredException} or \kw{InvalidKeyException} in certain edge cases.\\


    \section{dynamic properties}\label{sec:dynamic_properties}
    
    The \kw{OasysBackendState} instance allows assigning values to dynamically named properties. When you assign or read a property, magic methods intercept the call and route it to the database where the values are serialized into a JSON column.\\
    Besides getting and setting values, the default PHP commands of \kw{isset()} and \kw{unset()} are also supported for state properties.
    



    \section{instance methods}\label{sec:instance_methods}

    The following public methods are available on an \kw{OasysBackendState} instance.\\

    \begin{variable_properties}{6.5cm}{10.5cm}
        \hline
        getStateId() & Returns the active \kw{stateId} string (from the cookie). Generates and stores a new one if it doesn't exist.\\
        rotateStateId() & Cycles the current \kw{stateId} and issues a new cookie. Helps mitigate session fixation attacks.\\
        eraseState() & Deletes the current state record entirely from the database and instructs the browser to delete the cookie.\\
        isStateActive() & Checks the database to verify if the current instance's \kw{stateId} hasn't exceeded the configured timeout.\\
        getAllStateData(\$unwrap = true) & Returns an array or a raw JSON string of all data stored for the current \kw{stateId}.\\
        nukeAllStatesExceptCurrent() & Deletes all backend states in the database except for the current instance's \kw{stateId}.\\
        backupState() & Temporarily stores the current state data in memory (without unwrapping) to allow restoration later.\\
        restoreState() & Inserts or overwrites the database record for the current \kw{stateId} with the previously backed-up data.\\
        \hline
    \end{variable_properties}

    \subsection{getAllStateData parameters}\label{subsec:method_getallstatedata}
    \begin{parameters}
        \$unwrap & bool & Optional parameter, defaults to true. If false, returns the raw JSON string instead of an array.\\
    \end{parameters}
    
    \section{static methods}\label{sec:static_methods}

    Static methods allow you to interact with the backend state system globally without directly instantiating the state data of the current user.\\

    \begin{variable_properties}{6cm}{11cm}
        \hline
        getInstance() & Returns the singleton instance of the class. If it doesn't exist, it is initialized and the timestamp is updated.\\
        browserHasActiveState() & Checks if a cookie is present and if its corresponding \kw{stateId} is still active in the database.\\
        isStateIdActive(\$stateId) & Verifies if a specific \kw{stateId} provided in the arguments is active in the database.\\
        getNumberOfActiveClients() & Returns the count of all active states in the database, or -1 if the count cannot be determined. A custom timeout (in minutes) can be passed.\\
        fetchAllActiveStates() & Returns an array of all active states, including their data, modification date, and inactivity time.\\
        \hline
    \end{variable_properties}
    
    \subsection{isStateIdActive parameters}\label{subsec:method_isstateidactive}
    \begin{parameters}
        \$stateId\textsuperscript{*} & string & The specific 10-byte hex \kw{stateId} to check against the database.\\
    \end{parameters}

    \subsection{getNumberOfActiveClients parameters}\label{subsec:method_getnumberofactiveclients}
    \begin{parameters}
        \$timeOut & int & An optional inactivity limit in minutes. If omitted, it defaults to the \kw{backendInactivityTimeout} setting.\\
    \end{parameters}
