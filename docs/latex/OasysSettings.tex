    \section{description}\label{sec:description}

    The \kw{OasysSettings} class is a Singleton responsible for loading, managing, and distributing system-wide configuration, languages, skins, and module properties. It aggregates default configurations, merges them with overrides persisted in the database, and safely exposes them to the backend and frontend.\\
    
    Additionally, this class manages dynamic user-specific configurations, applying user group capabilities (such as editor buttons) and validating interface languages upon login.


    \section{usage}\label{sec:usage}

    Initialization typically happens at the bootstrap level via the main \kw{OasysApp} class instance, which is required by the constructor. After that, it can be retrieved from the public property \kw{config} of the OasysApp instance.\\

    \begin{exampleBox}{Example}
        Fetching a specific property:\\[0.1cm]
        \kw{\$maxUpload = \$settings->getProperty('upload\_max\_filesize');}\\[0.5cm]
        Loading user-specific settings after login:\\[0.1cm]
        \kw{\$settings->fetchUserSettings(\$userId, \$forceLang, \$userGroup);}
    \end{exampleBox}
    
    \vspace{0.5cm}
    \textbf{Dependencies:}\\
    This class relies on the \kw{OasysApp} class for initial injection, \kw{rixPDO} for database interactions, and \kw{settingsDefault.php} for its baseline configurations.\\


    \section{public properties}\label{sec:public_properties}
    
    The \kw{OasysSettings} instance maintains several public arrays that contain the runtime state of the application's configuration.
    
    \begin{variable_properties}{4cm}{13cm}
        \hline
        \$settings & The associative array containing all currently active merged settings (defaults combined with database values and user overrides).\\
        \$languages & Available system languages fetched from the \kw{languages} table.\\
        \$skins & Available skins parsed dynamically from the file system (base and module skins).\\
        \hline
    \end{variable_properties}


    \section{instance methods}\label{sec:instance_methods}

    The following public methods are available on an \kw{OasysSettings} instance.\\

    \begin{variable_properties}{6.5cm}{10.5cm}
        \hline
        getProperty(\$property) & Returns the value of a specific setting by its key.\\
        getSettingsArray() & Returns a reference to the main \kw{\$settings} array.\\
        getDefaults() & Returns the base default settings array before any database or user overrides were applied.\\
        getJSSafeSettings() & Returns an array of settings specifically filtered (excluding ones marked \kw{noJS}) to be safely passed to the frontend client.\\
        getLanguages() & Returns the array of active languages.\\
        getSkins() & Returns the array of available skins.\\
        fetchUserSettings(\ldots) & Fetches and merges user-specific database overrides and aggregates editor button permissions across a user's assigned groups.\\
        getIntLang(\ldots) & Determines the correct interface language based on user preference, forced input, or browser HTTP headers.\\
        getDatabaseInstance() & Returns the \kw{rixPDO} instance injected during construction.\\
        \hline
    \end{variable_properties}
    
    \subsection{fetchUserSettings parameters}\label{subsec:method_fetchusersettings}
    \begin{parameters}
        \$userId\textsuperscript{*} & string & The unique identifier of the user.\\
        \$userGroup\textsuperscript{*} & array & An array of user group IDs utilized to parse aggregate access permissions.\\
        \$forceLang & string & An optional language code to force (e.g., from the login screen or query string).\\
    \end{parameters}
    

    \section{static methods}\label{sec:static_methods}

    \begin{variable_properties}{6.5cm}{10.5cm}
        \hline
        getInstance(\$app) & Returns the singleton instance. If it doesn't exist, it requires an \kw{OasysApp} instance to initialize.\\
        findSkins() & Scans the file system (both base skins and module skins) to parse \kw{properties.json} files and build the skins array.\\
        findMods() & Scans the \kw{modules} folder to find and parse installed module capabilities via their \kw{editor.json} files.\\
        establishRootURL() & Determines the absolute web root URL based on server configuration.\\
        establishJSRootURL(\$url) & Modifies the root URL to account for server context prefixes, primarily used for linking JavaScript and CSS assets.\\
        \hline
    \end{variable_properties}
