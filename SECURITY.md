# Security Policy

## Supported versions

Security updates are provided for the latest released version of OASYS.
Users should update to the most recent release before reporting a problem that
may already have been corrected.

## Reporting a vulnerability

Do not report suspected vulnerabilities through a public GitHub issue,
discussion, or pull request.

Please report vulnerabilities privately by email to
[oasys@uni.lu](mailto:oasys@uni.lu).

Include as much of the following information as possible:

- The affected OASYS version.
- The installation environment and relevant configuration details.
- A description of the vulnerability and its potential impact.
- Clear steps for reproducing the problem.
- Relevant logs, screenshots, or proof-of-concept material, with personal and
  confidential information removed.
- Whether the vulnerability is already public or has been shared with anyone
  else.

We will review the report and contact you if further information is required.
Please allow us a reasonable opportunity to investigate and correct the issue
before publishing or sharing details publicly.

## Scope

This policy covers vulnerabilities in OASYS source code distributed through
the official OASYS repository and releases. Problems involving a particular
deployment, server configuration, or third-party service may need to be
addressed by the organization operating that installation.
