# OASYS

OASYS is a flexible, open-source platform for creating, delivering, and
evaluating digital assessments. It is designed for education, training,
research, certification, and large-scale assessment.

OASYS was originally developed for Luxembourg's national school monitoring
programme, Épreuves Standardisées (ÉpStan), and has been used since 2010 for
large-scale assessments, experimental studies, and survey-based data
collection.

## Features

- Web-based operation on computers, tablets, and smartphones.
- Multilingual assessment content, including English, French, German, and
  Luxembourgish, with support for additional languages.
- Real-time monitoring of test sessions, participant progress, and connection
  issues.
- Single-choice, multiple-choice, choice-matrix, open-text, inline-text, and
  slider interactions.
- Audio, video, and image integration.
- Concept maps and other interactive assessment formats.
- Flexible test templates, navigation, timing, and availability settings.
- Resumable interrupted assessments.
- Assessment, results, user, and media management tools.

For an overview, downloads, and information about getting started, visit
[oasys.lu](https://oasys.lu/).
